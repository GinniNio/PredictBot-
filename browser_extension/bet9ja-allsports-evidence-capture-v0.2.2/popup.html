Bet9ja All-Sports Evidence Capture

Stage 1: saves the raw, unparsed page source of whatever Bet9ja page is currently open so a real fixture parser can be built against it. Captures nothing about fixtures, odds, or your account -- just the page's own HTML.

Stage 3: sport walker (experimental)

Untested against a real Bet9ja session -- every click-to-render timeout in sport_walker.js is an unverified placeholder. Start on a page with the left sidebar visible (any prematch or competition page). This clicks through every group/competition for the sport you pick; leave the caps below empty to visit everything, or set them for a small first test.

Run automatically while Chrome is open

Every few hours the walker opens its own Bet9ja tab in the background, walks each sport below, and sends the captures to the PredictBot app (no download). Chrome must be open and the app running.
