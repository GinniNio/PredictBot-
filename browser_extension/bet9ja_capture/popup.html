PredictBot · Bet9ja Fixture Capture

Reads only the fixture markets visible on the current tab. Never reads cookies, tokens, balances, account details, or betslip contents. Makes no network requests.

Read-only. Open pre-match tickets only -- no bet placement, no cashout, no live/Zoom/Virtual tickets. Ticket-boundary selectors are unverified placeholders pending real-page validation; see TICKET_REAL_PAGE_VALIDATION.md.

Navigates the tab to sports.bet9ja.com/sportPage/1/competitions if not already there, then selects every country's competitions in batches and clicks Show Leagues to capture each batch's fixtures (ordinary 1X2 only). Progress is checkpointed to this browser's local storage after every batch, so a slow/failed competition, a cancel, or a closed popup never loses prior work — Resume continues from the first still-PENDING competition (matched by its own stable id, never by position); Retry failed competitions re-attempts only ones marked FAILED. See SOCCER_ALL_COMPETITIONS_VALIDATION.md for validation status.

Open from My Bets · Settled Bets. Walks every numbered results page, expanding each ticket, and downloads one file of Bet9ja's own recorded settlement -- never a recalculated outcome, never a ledger update. Only explicit "Won"/"Lost" outcomes are recognized so far; see SETTLED_BETS_REAL_PAGE_VALIDATION.md.
